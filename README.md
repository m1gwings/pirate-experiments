# Experiments for the PIRATE algorithm

Cristiano Migali, Gianmarco Genalti, Alberto Maria Metelli, and Marco Mussi

## How to Run the Experiments
Use `setup_env.sh` to setup a Conda environment with all the required packages.
To run the experiments execute the code in the main file (`main.py`).
The results will be saved in the `output` folder.
